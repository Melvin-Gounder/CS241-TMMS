# Demonstration Guide

1. Start XAMPP Apache and MySQL and import the SQL file.
2. Run the project with Java 17.
3. Open the public traffic page and show the four junctions in the fixed order.
4. Log in as the TMC operator and show live counts, speed, congestion and adaptive green time.
5. Trigger an emergency vehicle using a valid identifier such as `AB123`; explain that priority lasts 30 seconds.
6. Demonstrate that a manual override lasts 60 seconds and is blocked during emergency priority.
7. Log in as the administrator and show user/device/incident information plus the phpMyAdmin shortcut.
8. Explain the layered architecture and testing approach.
